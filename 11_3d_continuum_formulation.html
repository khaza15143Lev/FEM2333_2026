CEE 2333 — Fundamentals of the Finite Element Method

Lecture: 3-D Continuum Formulation

Prof. Lev Khazanovich

Learning Objectives

By the end of this lecture, you should be able to:

  • Extend the 1D/2D finite element concepts (shape functions, stiffness matrix, governing equation) to a general 3D solid, and describe the geometry and degrees of freedom of an 8-node hexahedral element.
  • Write the six independent strain components and six independent stress components at a point in Cartesian coordinates, and compute them from a given displacement field.
  • State the three differential equilibrium equations and explain why the stress tensor is symmetric.
  • Recall and use the generalized Hooke’s law \(\{\sigma\}=[D]\{\varepsilon\}\) for a symmetric material matrix \([D]\) (the full derivation, the explicit isotropic entries, and the 36→21→9→2 constant-count reduction are covered on the Constitutive Relations page).
  • Apply the principle of minimum potential energy and the Ritz (finite element) approximation to derive the strain-displacement matrix \([B]\), the element stiffness matrix \([K]\), and the element load vector \(\{f^e\}\) for a 3D element.

Roadmap. Everything in this lecture funnels toward one destination: turning a continuum elasticity problem into a matrix equation a computer can solve. Here is the path:

The model used in this lecture: small strain + linear elasticity + static equilibrium + isotropy + homogeneity (same five assumptions built up on Constitutive Relations, with one addition specific to this lecture — static equilibrium: no inertial (mass × acceleration) terms, so the equilibrium equations in §5 balance only stresses against body forces, not against dynamic loads). Everything from §1 onward assumes all five hold; if a problem has large deformations, plasticity, dynamic loading, or an anisotropic material, the formulation built here needs modification before it applies.

Where the assumptions matter. What breaks, and what has to change, if each assumption is violated:

AssumptionIf violatedWhat changes in this formulation
Small strainLarge displacements or rotations → geometric nonlinearityThe strain–displacement relations gain quadratic terms, equilibrium must be written on the deformed geometry, and \([B]\) depends on the current displacements.
Linear elasticityPlasticity, damage, hyperelasticity → material nonlinearity\(\{\sigma\}=[D]\{\varepsilon\}\) no longer holds; \([D]\) becomes a tangent that changes with the state, and \([K]\{u\}=\{F\}\) must be solved iteratively.
Static equilibriumDynamic loading → inertia termsA mass term (density × acceleration) enters the equilibrium equations, so a mass matrix \([M]\) appears alongside \([K]\).
IsotropyComposites, wood, single crystals → anisotropyThe two-constant isotropic \([D]\) is replaced by a full (or orthotropic) \([D]\) with more independent constants; \([B]\) is unchanged.
HomogeneityGraded or layered material → \(E,\nu\) vary in space\([D]\) becomes \([D(\vec x)]\) and must stay inside the integral \(\int [B]^T[D][B]\,dV\).

1. Bridging from 1D/2D to 3D

In the 1D (bar/Ritz) and 2D (plane stiffness) formulations covered earlier in this course, you already built every piece of the finite element method you need for 3D:

Concept 1D / 2D version 3D version (this lecture)
Unknown field axial displacement \(u(x)\) displacement vector \(\vec u(\vec x) = \{u, v, w\}^T\)
Strain \(\varepsilon = du/dx\) 6 strain components: 3 normal + 3 shear
Stress \(\sigma = E\varepsilon\) 6 stress components, related through a \(6\times 6\) material matrix \([D]\)
Shape functions \(N_i(x)\) \(N_i(\vec x)\), now functions of \(x,y,z\)
Governing equation \([K]\{u\} = \{F\}\) \([K]\{u^e\} = \{f\}\) (same form, larger matrices)
Element 2-node bar / 4-node quad 8-node hexahedron (used throughout this lecture)

Nothing about the logic of the finite element method changes. What changes is the bookkeeping: strain and stress become 6-component vectors instead of scalars, and the material law becomes a \(6\times 6\) matrix instead of a single modulus \(E\). Keep this table in mind — every equation below is the direct 3D generalization of something you have already derived.

2. Geometry and Displacements of a 3D Element

We describe the position of any point in the element with the vector

\[\vec x = \{x\ \ y\ \ z\}^T\]

This is an 8-node hexahedral (brick) element — the standard 3D analogue of the 2-node bar and 4-node quadrilateral you used previously. All 8 nodes carry three displacement degrees of freedom each (one per coordinate direction), for \(8\times 3 = 24\) total degrees of freedom per element.

The displacement at any point is

\[\vec u(\vec x) = \{u(\vec x)\ \ v(\vec x)\ \ w(\vec x)\}^T\]

i.e., displacement components in the \(x\)-, \(y\)-, and \(z\)-directions, respectively. At node 1, for example, the nodal displacements are \(u_1, v_1, w_1\).

Check your understanding: Why 24 DOF?

How many total degrees of freedom does the 8-node hexahedral element have, and why?

Answer: 24. Each of the 8 nodes carries 3 translational displacement components (\(u_i, v_i, w_i\)), one per coordinate direction, so \(8 \times 3 = 24\).

3. Strains in Cartesian Coordinates

Extensional (normal) strains:

\[\varepsilon_{xx} \equiv \varepsilon_x = \frac{\partial u}{\partial x}, \qquad \varepsilon_{yy} \equiv \varepsilon_y = \frac{\partial v}{\partial y}, \qquad \varepsilon_{zz} \equiv \varepsilon_z = \frac{\partial w}{\partial z}\]

Shear strains (engineering convention, \(\gamma = 2\varepsilon\) — the one used in the stiffness formulation later in this lecture):

\[\gamma_{xy} = \gamma_{yx} = \frac{\partial u}{\partial y} + \frac{\partial v}{\partial x}, \qquad \gamma_{xz} = \gamma_{zx} = \frac{\partial u}{\partial z} + \frac{\partial w}{\partial x}, \qquad \gamma_{yz} = \gamma_{zy} = \frac{\partial v}{\partial z} + \frac{\partial w}{\partial y}\]

Convention used throughout. Throughout this lecture (and in the stiffness-matrix derivation) we use engineering shear strains \(\gamma_{ij}\). The factor of ½ appears only when the strain is written as a tensor.
Strain tensor (engineering shear components)
\[\begin{bmatrix} \varepsilon_{xx} & \gamma_{xy}/2 & \gamma_{xz}/2 \\ \gamma_{xy}/2 & \varepsilon_{yy} & \gamma_{yz}/2 \\ \gamma_{xz}/2 & \gamma_{yz}/2 & \varepsilon_{zz} \end{bmatrix}\]
The tensor uses the tensorial shear strain \(\gamma/2\) on the off-diagonal. For the FEM formulation later in this lecture we instead collect the engineering shear strain \(\gamma\) (no factor of 2) into a 6-vector: \(\{\varepsilon\} = \{\varepsilon_{xx}, \varepsilon_{yy}, \varepsilon_{zz}, \gamma_{xy}, \gamma_{xz}, \gamma_{yz}\}^T\) (engineering shears — no factor of ½) — this is the same engineering-vs-tensorial distinction, and the same work-conjugacy argument for why \(\{\varepsilon\}\) uses \(\gamma\) rather than \(\gamma/2\), covered in full on §2.0 of Constitutive Relations. Here we only need the bottom line: \(\{\sigma\}\) and \(\{\varepsilon\}\) stay work-conjugate — i.e. \(\{\sigma\}^T\{\varepsilon\}\) gives the correct strain energy density — without carrying extra factors of 2 through the stiffness derivation.

Worked Example — Computing Strains from a Displacement Field

Given the displacement field

\[u(x,y,z) = a_1x^2y^2 + b_1x^2y + c_1xy + d_1\] \[v(x,y,z) = a_2x^2y^2 + b_2x^2y + c_2xy + d_2\] \[w(x,y,z) = a_3xy^2z + b_3xyz + c_3x^2yz + d_3\]

Normal strains:

\[\varepsilon_x = \frac{\partial u}{\partial x} = 2a_1xy^2 + 2b_1xy + c_1y\]

\[\varepsilon_y = \frac{\partial v}{\partial y} = 2a_2x^2y + b_2x^2 + c_2x\]

\[\varepsilon_z = \frac{\partial w}{\partial z} = a_3xy^2 + b_3xy + c_3x^2y\]

Shear strains:

\[\gamma_{xy} = \frac{\partial u}{\partial y} + \frac{\partial v}{\partial x} = \left(2a_1x^2y + b_1x^2 + c_1x\right) + \left(2a_2xy^2 + 2b_2xy + c_2y\right)\]

\[\gamma_{xz} = \frac{\partial u}{\partial z} + \frac{\partial w}{\partial x} = a_3y^2z + b_3yz + 2c_3xyz\]

\[\gamma_{yz} = \frac{\partial v}{\partial z} + \frac{\partial w}{\partial y} = 2a_3xyz + b_3xz + c_3x^2z\]

This is exactly the same differentiation procedure you used for 1D and 2D displacement fields — there are simply more terms and more partial derivatives to track.

Worked Numerical Example — From Displacement to Stress

To make the bookkeeping concrete before meeting the full \([B]\) matrix, here is the same procedure with numbers instead of unknown coefficients. Take the simple linear displacement field (SI units; the numbers below are illustrative rather than physically realistic):

\[u = 0.0020x + 0.0010y, \qquad v = 0.0005x + 0.0015y, \qquad w = 0.0010z\]

Step 1 — strains (constant everywhere, since every displacement gradient here is constant):

\[\varepsilon_{xx} = \frac{\partial u}{\partial x} = 0.0020, \qquad \varepsilon_{yy} = \frac{\partial v}{\partial y} = 0.0015, \qquad \varepsilon_{zz} = \frac{\partial w}{\partial z} = 0.0010\]

\[\gamma_{xy} = \frac{\partial u}{\partial y} + \frac{\partial v}{\partial x} = 0.0010 + 0.0005 = 0.0015, \qquad \gamma_{xz} = 0, \qquad \gamma_{yz} = 0\]

so \(\{\varepsilon\} = \{0.0020,\ 0.0015,\ 0.0010,\ 0.0015,\ 0,\ 0\}^T\). (These strain magnitudes are unrealistically large for linear elasticity; they are chosen only so the arithmetic stays readable.)

Step 2 — stresses via the isotropic \([D]\) matrix (§6). With \(E = 200\) GPa and \(\nu = 0.25\), the scale factor \(E/[(1+\nu)(1-2\nu)] = 320\) GPa sets every coefficient below: it gives normal-stress coefficients \(320(1-\nu)=240\) GPa and \(320\nu=80\) GPa, and a shear coefficient \(320\cdot\frac{1-2\nu}{2}=80\) GPa — which is just \(G\), as it must be. (Explicit entries and a live calculator for \([D]\) are on Constitutive Relations, §calculator; feel free to feed the same \(\{\varepsilon\}\) from Step 1 into that calculator now and confirm it returns the same stresses computed below.)

\[\sigma_{xx} = 240(0.0020) + 80(0.0015) + 80(0.0010) = 0.68 \text{ GPa} = 680 \text{ MPa}\]

\[\sigma_{yy} = 80(0.0020) + 240(0.0015) + 80(0.0010) = 0.60 \text{ GPa} = 600 \text{ MPa}\]

\[\sigma_{zz} = 80(0.0020) + 80(0.0015) + 240(0.0010) = 0.52 \text{ GPa} = 520 \text{ MPa}\]

\[\tau_{xy} = 80(0.0015) = 0.12 \text{ GPa} = 120 \text{ MPa}, \qquad \tau_{xz} = \tau_{yz} = 0\]

You can check this against the live \([D]\) calculator on Constitutive Relations: enter \(\sigma_x=0.68\), \(\sigma_y=0.60\), \(\sigma_z=0.52\), \(\tau_{xy}=0.12\) (all in GPa, matching the units used above), \(E=200\) GPa, \(\nu=0.25\), and confirm the reported strains match \(\{\varepsilon\}\) above.

Every entry above came from the same two operations you will repeat, symbolically, for the full 8-node element: differentiate the displacement field to get \(\{\varepsilon\}\), then multiply by \([D]\) to get \(\{\sigma\}\). The only thing that changes for a real element is that \(\{\varepsilon\}\) comes from \([B]\{u^e\}\) instead of a displacement field given in closed form.

4. Stresses in Cartesian Coordinates

Stress notation (face, direction, the normal-vs-shear distinction, and the face/direction figure) is built up from scratch in §1.0 of Constitutive Relations. Here we only need the result: the first subscript of \(\tau_{ij}\) identifies the face (by its outward-normal direction), the second identifies the direction the stress acts in.

Component Type Acts on face Acts in direction
\(\sigma_x\)normal\(x\)\(x\)
\(\sigma_y\)normal\(y\)\(y\)
\(\sigma_z\)normal\(z\)\(z\)
\(\tau_{xy}=\tau_{yx}\)shear\(x\) (or \(y\))\(y\) (or \(x\))
\(\tau_{xz}=\tau_{zx}\)shear\(x\) (or \(z\))\(z\) (or \(x\))
\(\tau_{yz}=\tau_{zy}\)shear\(y\) (or \(z\))\(z\) (or \(y\))

The shear rows collapse to one independent value each by symmetry of the stress tensor (shown in the equilibrium section below):

\[\tau_{xy} = \tau_{yx}, \qquad \tau_{yz} = \tau_{zy}, \qquad \tau_{xz} = \tau_{zx}\]

so there are only 6 independent stress components: \(\sigma_x, \sigma_y, \sigma_z, \tau_{xy}, \tau_{xz}, \tau_{yz}\).

5. Equilibrium Equations

Force equilibrium on a differential volume (\(S\) = surface, \(V\) = volume, \(\{q\}=\{q_x,q_y,q_z\}^T\) = body force per unit volume, \(T^n\) = surface traction) requires:

\[\iint_S T_i^n\, dS + \iiint_V q_i\, dV = 0\]

(Using the divergence theorem, the surface traction integral is converted into a volume integral of stress gradients — \(\iint_S T_i^n\, dS = \iiint_V \partial \sigma_{ji}/\partial x_j\, dV\) — so the entire equation becomes a single volume integral. Because this must hold for every differential volume, the integrand itself must vanish, which is what turns the integral statement into the differential equations below.)

In index notation, the resulting equilibrium condition can be written concisely as:

\[\frac{\partial \sigma_{ji}}{\partial x_j} + q_i = 0 \qquad \text{for } i = x, y, z\]

Here the first subscript of \(\sigma_{ji}\) is the one being summed over (matching the face-normal/differentiation direction \(x_j\)), and the second is the fixed direction of the equation — consistent with the face-first convention from §4, without yet needing to invoke stress symmetry. Symmetry of the stress tensor has not been used so far; it follows from moment balance, shown later in this section.

Expanding this for \(i=x,y,z\) gives the three differential equilibrium equations:

\[\frac{\partial \sigma_x}{\partial x} + \frac{\partial \tau_{yx}}{\partial y} + \frac{\partial \tau_{zx}}{\partial z} + q_x = 0\]

\[\frac{\partial \tau_{xy}}{\partial x} + \frac{\partial \sigma_y}{\partial y} + \frac{\partial \tau_{zy}}{\partial z} + q_y = 0\]

\[\frac{\partial \tau_{xz}}{\partial x} + \frac{\partial \tau_{yz}}{\partial y} + \frac{\partial \sigma_z}{\partial z} + q_z = 0\]

Summing moments about the element’s center — where, in the limit as the element shrinks, only the surface tractions contribute — gives the symmetry of the stress tensor used above:

\[\sigma_{ij} = \sigma_{ji} \ \Rightarrow\ \tau_{xy}=\tau_{yx}, \quad \tau_{yz}=\tau_{zy}, \quad \tau_{zx}=\tau_{xz}\]

Strong form vs. weak form. The three differential equilibrium equations above, together with the boundary conditions introduced in §7, are the strong form of the elasticity problem: a set of pointwise differential equations that the exact displacement field must satisfy at every point in the body. The minimum potential energy statement in §8 is the corresponding weak form — a single integral (energy) statement that a sufficiently smooth displacement field satisfies if and only if it also satisfies the strong form. This is the same strong-form/weak-form relationship you will meet again as Galerkin’s method in later courses: the finite element method discretizes the weak form directly (via the Ritz approximation in §9), which is why it is the energy statement — not the differential equilibrium equations themselves — that actually gets programmed.

6. Constitutive Law: Generalized Hooke’s Law

The general linear elastic relationship between stress and strain is

\[\{\sigma\} = [D]\{\varepsilon\}, \qquad \text{or, with initial strains: } \{\sigma\} = [D](\{\varepsilon\} - \{\varepsilon_0\})\]

where \([D]\) is a symmetric \(6\times 6\) material matrix. For an isotropic material — the case used throughout the rest of this course — \([D]\) depends on only two constants, \(E\) and \(\nu\). The explicit entries of \([D]\), the derivation that gets there (1D bar law → Poisson’s effect → 3D superposition), the inverse (compliance) form, the 36→21→9→2 constant-count reduction for general/orthotropic/isotropic materials, and a live calculator you can use to build intuition for how \([D]\) changes with \(E\) and \(\nu\) are all on §8.0 of Constitutive Relations. What we carry forward from here is just this: \([D]\) is a known, symmetric matrix that turns strain into stress, and it is that matrix — whatever its entries — that gets inserted into the energy expression below and, ultimately, into the element stiffness integral.

Initial strains: the term \(\{\varepsilon_0\}\) accounts for strains that exist before any load is applied — thermal expansion, shrinkage, or prestrain. For a purely mechanical problem at a reference temperature, \(\{\varepsilon_0\}=0\) and the equation reduces to \(\{\sigma\}=[D]\{\varepsilon\}\). When thermal strains are present, you subtract them from the total strain before computing stress: \(\{\sigma\} = [D](\{\varepsilon_{\text{total}}\} - \{\varepsilon_{\text{thermal}}\})\).

7. Boundary Conditions

Two types of boundary conditions can be prescribed on the surface of the body, \(S = S_T \cup S_u\):

Traction (Neumann) boundary conditions, prescribed on \(S_T\), the portion of the surface where surface tractions \(p_x, p_y, p_z\) are known:

\[\sigma_x n_x + \tau_{yx} n_y + \tau_{zx} n_z = p_x(\vec x)\] \[\tau_{xy} n_x + \sigma_y n_y + \tau_{zy} n_z = p_y(\vec x)\] \[\tau_{xz} n_x + \tau_{yz} n_y + \sigma_z n_z = p_z(\vec x)\]

where \(n_x, n_y, n_z\) are the direction cosines of the outward normal to the surface.

Displacement (Dirichlet) boundary conditions, prescribed on \(S_u\), the portion of the surface where displacements are known:

\[u(\vec x) = U(\vec x), \qquad v(\vec x) = V(\vec x), \qquad w(\vec x) = W(\vec x) \quad \text{for } \vec x \in S_u\]

Prescribed quantity Surface region Also known as
Traction BC \(p_x, p_y, p_z\) \(S_T\) Neumann
Displacement BC \(U, V, W\) \(S_u\) Dirichlet

Every point on the boundary belongs to exactly one of these two regions (or has some components prescribed as displacement and others as traction).

8. Principle of Minimum Potential Energy

The principle itself, and its derivation from the strong form, is covered in detail for the 1D bar and 2D frame element in Energy Methods and the Finite Element Formulation. What follows extends the same energy statement to a general 3D solid.

For a linear elastic body subjected to body forces \(\{q\}=\{q_x,q_y,q_z\}^T\) and surface tractions \(\{p\}=\{p_x,p_y,p_z\}^T\), causing displacements \(\{u\}=\{u,v,w\}^T\), strains \(\{\varepsilon\}\), and stresses \(\{\sigma\}\), the potential energy \(\Pi\) is the strain energy minus the potential energy of the loads:

Strain energy of the elastic body:

\[U = \frac{1}{2}\int_V \left(\sigma_{xx}\varepsilon_{xx} + \sigma_{yy}\varepsilon_{yy} + \sigma_{zz}\varepsilon_{zz} + \tau_{xy}\gamma_{xy} + \tau_{xz}\gamma_{xz} + \tau_{yz}\gamma_{yz}\right) dV = \frac{1}{2}\int_V \{\sigma\}^T\{\varepsilon\}\, dV\]

(Compare to the 1D case you already know: \(U = \frac{1}{2}\int_0^L \sigma\varepsilon A\, dx\) — same idea, now integrated over a volume with 6 stress/strain components instead of 1.)

Potential energy of the loads:

\[W = \int_V \left(uq_x+vq_y+wq_z\right) dV + \int_{S_T} \left(up_x+vp_y+wp_z\right) dS = \int_V \{u\}^T\{q\}\, dV + \int_{S_T} \{u\}^T\{p\}\, dS\]

Total potential energy:

\[\Pi = \frac{1}{2}\int_V \{\sigma\}^T\{\varepsilon\}\, dV - \int_V \{u\}^T\{q\}\, dV - \int_{S_T} \{u\}^T\{p\}\, dS\]

Principle of minimum potential energy: Among all admissible displacement fields, the one that satisfies the equilibrium equations also renders \(\Pi\) a minimum. An “admissible displacement field” is one for which:

  1. First derivatives of the displacement components exist, and
  2. It satisfies the boundary conditions on \(S_u\).

For a continuous system, solving the elastic problem reduces to finding the displacement field that minimizes \(\Pi\). For this displacement-based linear-elastic formulation, the finite element approximation can be viewed as a Rayleigh–Ritz approximation using piecewise shape functions in place of the displacement field's nodal values. (Other finite element formulations — e.g. mixed, hybrid, or displacement-discontinuous methods — depart from this Ritz picture; the identification made here applies to the standard displacement-based element built in this lecture.)

9. Finite Element Approximation (Rayleigh–Ritz Method)

See Energy Methods and the Finite Element Formulation for a full worked introduction to the Ritz method on a simpler 1D/2D element before working through the 3D generalization below.

The Ritz method approximates the unknown displacement field as a linear combination of known shape functions \(N_i(\vec x)\) and unknown nodal parameters \(u_i, v_i, w_i\):

\[u(\vec x) \approx \sum_{i=1}^n N_i(\vec x)\, u_i, \qquad v(\vec x) \approx \sum_{i=1}^n N_i(\vec x)\, v_i, \qquad w(\vec x) \approx \sum_{i=1}^n N_i(\vec x)\, w_i\]

where \(n\) is the number of nodes in the element (\(n=8\) for the hexahedral element used in this lecture). The shape functions satisfy the interpolation property

\[N_i(\vec x) = \begin{cases} 1, & \vec x = \vec x_i \\ 0, & \vec x = \vec x_k,\ k \neq i\end{cases}\]

and the partition of unity condition:

\[\sum_{i=1}^n N_i(\vec x) = 1 \quad \text{everywhere in the element}\]

For the 8-node hexahedron, the shape functions are typically written in terms of the natural coordinates \((\xi,\eta,\zeta)\) introduced in the next lecture, and are trilinear — linear in each coordinate direction:

\[N_i(\xi,\eta,\zeta) = \frac{1}{8}(1 \pm \xi)(1 \pm \eta)(1 \pm \zeta)\]

where the sign pattern in each factor matches the sign of node \(i\)’s coordinate (e.g. the node at \((\xi,\eta,\zeta)=(1,1,1)\) uses all plus signs, the node at \((-1,1,1)\) uses a minus sign only on the \(\xi\) factor, and so on). These same functions interpolate both the geometry and the displacements — the isoparametric concept covered in the next lecture.

The shape functions above are written in the parent (natural) coordinates. How we map them onto a distorted physical element is the subject of the next lecture (Isoparametric Elements). For the derivation of \([K]\) that follows, we only need the existence of \(N_i(\vec x)\) and their derivatives — not yet the details of how \(\vec x\) and \((\xi,\eta,\zeta)\) relate.

In matrix form, for each displacement component:

\[u(\vec x) = [N_1(\vec x)\ N_2(\vec x)\ \cdots\ N_n(\vec x)]\begin{Bmatrix}u_1\\u_2\\\vdots\\u_n\end{Bmatrix}\]

and, stacking all three components, the full displacement vector at any point \(\vec x\) is written compactly as

\[\{u(\vec x)\} = [N(\vec x)]\{u^e\}\]

\[\underbrace{\{u(\vec x)\}}_{3\times 1} = \underbrace{[N(\vec x)]}_{3\times 3n}\ \underbrace{\{u^e\}}_{3n\times 1}\]

where \(\{u^e\}\) is the vector of all nodal displacements for the element (24 entries for the 8-node hexahedron: \(u_1,v_1,w_1,\dots,u_8,v_8,w_8\)).

Strain–Displacement Relationship

Differentiating the interpolated displacement field gives the strains directly in terms of nodal displacements. For example,

\[\varepsilon_{xx}(\vec x) = \frac{\partial u(\vec x)}{\partial x} = \frac{\partial}{\partial x}\sum_{i=1}^n N_i(\vec x)\, u_i = \sum_{i=1}^n N_{i,x}\, u_i\]

with \(N_{i,x} \equiv \partial N_i/\partial x\), and similarly for \(\varepsilon_{yy}, \varepsilon_{zz}\), and (combining derivatives of \(u\) and \(v\), \(u\) and \(w\), \(v\) and \(w\)) the three shear strains. Collecting all six strain components:

\[\{\varepsilon(\vec x)\} = [B(\vec x)]\{u^e\}\]

\[\underbrace{\{\varepsilon(\vec x)\}}_{6\times 1} = \underbrace{[B(\vec x)]}_{6\times 3n}\ \underbrace{\{u^e\}}_{3n\times 1}\]

where \([B]\) (the strain-displacement matrix) contains only derivatives of the shape functions.

Deriving the [B] Matrix

To see explicitly where the entries of \([B]\) come from, write out the first strain component. Since \(u(\vec x) = \sum_{i=1}^8 N_i(\vec x)\, u_i\) for the 8-node hexahedron:

\[\varepsilon_{xx} = \frac{\partial u}{\partial x} = \sum_{i=1}^8 \frac{\partial N_i}{\partial x}\, u_i = N_{1,x}u_1 + N_{2,x}u_2 + \cdots + N_{8,x}u_8\]

Because \(\varepsilon_{xx}\) does not depend on any of the \(v_i\) or \(w_i\) nodal values, the first row of \([B]\) — the row that, multiplied into \(\{u^e\}\), produces \(\varepsilon_{xx}\) — has zeros in every column except the \(u_i\) columns:

\[\text{row 1 of } [B] = \left[\, N_{1,x}\ \ 0\ \ 0\ \ \Big|\ \ N_{2,x}\ \ 0\ \ 0\ \ \Big|\ \ \cdots\ \ \Big|\ \ N_{8,x}\ \ 0\ \ 0\, \right]\]

The remaining five rows follow the same logic applied to \(\varepsilon_{yy}, \varepsilon_{zz}, \gamma_{xy}, \gamma_{xz}, \gamma_{yz}\), giving the full \(6\times 24\) matrix (shown here for node \(i\)’s three columns; the same block repeats for \(i=1,\dots,8\)):

\[[B] = \big[\,[B_1]\ \ [B_2]\ \ \cdots\ \ [B_8]\,\big], \qquad [B_i] = \begin{bmatrix} N_{i,x} & 0 & 0 \\ 0 & N_{i,y} & 0 \\ 0 & 0 & N_{i,z} \\ N_{i,y} & N_{i,x} & 0 \\ N_{i,z} & 0 & N_{i,x} \\ 0 & N_{i,z} & N_{i,y} \end{bmatrix}\]

Each \(6\times 3\) block \([B_i]\) multiplies the corresponding \(\{u_i, v_i, w_i\}^T\) triple from \(\{u^e\}\); stacking all eight blocks side by side gives the complete \(6\times 24\) matrix used in the stiffness integral below.

Show the full 6×24 [B] pattern

The eight 6×3 blocks side by side. Column headers name the nodal DOF each column multiplies; row labels name the strain it produces.

\[\begin{array}{r|ccc|ccc|ccc|ccc|ccc|ccc|ccc|ccc} & u_1 & v_1 & w_1 & u_2 & v_2 & w_2 & u_3 & v_3 & w_3 & u_4 & v_4 & w_4 & u_5 & v_5 & w_5 & u_6 & v_6 & w_6 & u_7 & v_7 & w_7 & u_8 & v_8 & w_8 \\ \hline \varepsilon_{xx} & N_{1,x} & 0 & 0 & N_{2,x} & 0 & 0 & N_{3,x} & 0 & 0 & N_{4,x} & 0 & 0 & N_{5,x} & 0 & 0 & N_{6,x} & 0 & 0 & N_{7,x} & 0 & 0 & N_{8,x} & 0 & 0 \\ \varepsilon_{yy} & 0 & N_{1,y} & 0 & 0 & N_{2,y} & 0 & 0 & N_{3,y} & 0 & 0 & N_{4,y} & 0 & 0 & N_{5,y} & 0 & 0 & N_{6,y} & 0 & 0 & N_{7,y} & 0 & 0 & N_{8,y} & 0 \\ \varepsilon_{zz} & 0 & 0 & N_{1,z} & 0 & 0 & N_{2,z} & 0 & 0 & N_{3,z} & 0 & 0 & N_{4,z} & 0 & 0 & N_{5,z} & 0 & 0 & N_{6,z} & 0 & 0 & N_{7,z} & 0 & 0 & N_{8,z} \\ \gamma_{xy} & N_{1,y} & N_{1,x} & 0 & N_{2,y} & N_{2,x} & 0 & N_{3,y} & N_{3,x} & 0 & N_{4,y} & N_{4,x} & 0 & N_{5,y} & N_{5,x} & 0 & N_{6,y} & N_{6,x} & 0 & N_{7,y} & N_{7,x} & 0 & N_{8,y} & N_{8,x} & 0 \\ \gamma_{xz} & N_{1,z} & 0 & N_{1,x} & N_{2,z} & 0 & N_{2,x} & N_{3,z} & 0 & N_{3,x} & N_{4,z} & 0 & N_{4,x} & N_{5,z} & 0 & N_{5,x} & N_{6,z} & 0 & N_{6,x} & N_{7,z} & 0 & N_{7,x} & N_{8,z} & 0 & N_{8,x} \\ \gamma_{yz} & 0 & N_{1,z} & N_{1,y} & 0 & N_{2,z} & N_{2,y} & 0 & N_{3,z} & N_{3,y} & 0 & N_{4,z} & N_{4,y} & 0 & N_{5,z} & N_{5,y} & 0 & N_{6,z} & N_{6,y} & 0 & N_{7,z} & N_{7,y} & 0 & N_{8,z} & N_{8,y} \end{array}\]
Sanity check — rigid-body motion must give zero strain. A body that only translates or rotates as a whole does not stretch or shear, so a correct \([B]\) must return \(\{\varepsilon\}=\{0\}\) for both motions.

Pure translation. Take \(u=c_x,\ v=c_y,\ w=c_z\), so every nodal value is the same constant (\(u_i=c_x\) for all \(i\), and likewise for \(v_i, w_i\)). Then, using the partition of unity \(\sum_i N_i = 1\),

\[\varepsilon_{xx} = \sum_i N_{i,x}\,c_x = c_x\,\frac{\partial}{\partial x}\Big(\sum_i N_i\Big) = c_x\,\frac{\partial (1)}{\partial x} = 0,\]

and the same argument gives \(\varepsilon_{yy}=\varepsilon_{zz}=\gamma_{xy}=\gamma_{xz}=\gamma_{yz}=0\). Hence \(\{\varepsilon\}=\{0\}\).

Infinitesimal rigid rotation. For small rotations \(\omega_x,\omega_y,\omega_z\) about the axes, the displacement field is

\[u = \omega_y z - \omega_z y, \qquad v = \omega_z x - \omega_x z, \qquad w = \omega_x y - \omega_y x.\]

The normal strains vanish because each component does not depend on its own coordinate (for example \(\partial u/\partial x = 0\)), and each shear strain is a difference that cancels:

\[\gamma_{xy} = \frac{\partial u}{\partial y} + \frac{\partial v}{\partial x} = -\omega_z + \omega_z = 0, \quad \gamma_{xz} = \omega_y - \omega_y = 0, \quad \gamma_{yz} = -\omega_x + \omega_x = 0.\]

This field is linear in \(x,y,z\), and the trilinear shape functions reproduce linear fields exactly, so \([B]\{u^e\}\) built from the nodal values of this field is also exactly zero.

Implication for debugging your own code: if a computed \([B]\) produces nonzero strain under a rigid translation or rotation, the shape-function derivatives, the node ordering, or the coordinate transformation feeding into \([B]\) has a bug — this is one of the fastest checks to run on a new element implementation before trusting any of its stress output.

Stress–Displacement Relationship

Combining the strain-displacement relationship with Hooke’s law, \(\{\sigma\} = [D]\{\varepsilon\}\):

\[\{\sigma(\vec x)\} = [D]\{\varepsilon(\vec x)\} = [D][B(\vec x)]\{u^e\}\]

(\([D]\) is constant here since the material is isotropic and homogeneous; write \([D(\vec x)]\) instead if the material properties vary in space.)

\[\underbrace{\{\sigma(\vec x)\}}_{6\times 1} = \underbrace{[D]}_{6\times 6}\ \underbrace{[B(\vec x)]}_{6\times 3n}\ \underbrace{\{u^e\}}_{3n\times 1}\]

Aside — checking units: carrying the dimensions all the way through catches the exact class of implementation error a matrix shape mismatch would throw at you before you ever run the code: \([N]\) is dimensionless (a pure interpolation weight); \([B]\) carries units of \(1/\text{length}\) (it's built from spatial derivatives of \([N]\)); \([D]\) carries units of stress; and each factor of \([B]\) inside \(K_e=\int B^T D B\, dV\) contributes a \(1/\text{length}\) while \(dV\) contributes \(\text{length}^3\), leaving \(K_e\) with units of \(\text{stress}\times\text{length} = \text{force}/\text{length}\) — exactly what a stiffness (force per unit displacement) should be.

Summary of the three relationships used from here on:

\[\{u\} = [N]\{u^e\} \qquad \{\varepsilon\} = [B]\{u^e\} \qquad \{\sigma\} = [D][B]\{u^e\}\]

10. Deriving the Element Stiffness Matrix

Step 1 — substitute displacement and strain approximations into \(\Pi\). Starting from

\[\Pi = \frac{1}{2}\int_V \sigma^T\varepsilon\, dV - \int_V \{u\}^T\{q\}\, dV - \int_S \{u\}^T\{p\}\, dS\]

substitute \(\{u\}=[N]\{u^e\}\) (so \(\{u\}^T = \{u^e\}^T[N]^T\)) and \(\{\varepsilon\}=[B]\{u^e\}\), \(\{\sigma\}=[D][B]\{u^e\}\) (so \(\{\sigma\}^T = \{u^e\}^T[B]^T[D]^T = \{u^e\}^T[B]^T[D]\), using symmetry of \([D]\)):

\[\Pi = \frac{1}{2}\int_V \{u^e\}^T[B]^T[D][B]\{u^e\}\, dV - \int_V \{u^e\}^T[N]^T\{q\}\, dV - \int_S \{u^e\}^T[N]^T\{p\}\, dS\]

Step 2 — pull the constant nodal displacement vector \(\{u^e\}\) outside each integral (it does not depend on \(\vec x\)):

\[\Pi = \{u^e\}^T\left[\frac{1}{2}\int_V [B]^T[D][B]\, dV\right]\{u^e\} - \{u^e\}^T\int_V [N]^T\{q\}\, dV - \{u^e\}^T\int_S [N]^T\{p\}\, dS\]

Pulling \(\{u^e\}^T\) and \(\{u^e\}\) outside the integrals is legitimate only because the nodal values are independent of \(\vec x\); all spatial dependence sits in \([N]\) and \([B]\).

Define the element stiffness matrix (symmetric, since \([D]\) is symmetric):

\[\underbrace{[K]}_{3n\times 3n} = \int_V \underbrace{[B]^T}_{3n\times 6}\, \underbrace{[D]}_{6\times 6}\, \underbrace{[B]}_{6\times 3n}\, dV\]

For the 8-node hexahedron, \(n=8\), so \([K]\) is \(24\times 24\) — matching the 24 degrees of freedom in \(\{u^e\}\) (3 per node × 8 nodes). Each factor's shape has to line up for the matrix multiply to even be defined: \([B]^T\) is \(3n\times 6\), times \([D]\)'s \(6\times 6\), times \([B]\)'s \(6\times 3n\), giving \(3n\times 3n\) — if your own code's shapes don't multiply out this way, something upstream (usually the number of nodes or DOFs per node) is wrong.

Step 3 — minimize \(\Pi\) with respect to the nodal displacements. This uses the same quadratic-form calculus you used for the 1D and 2D stiffness derivations:

Aside — differentiating a quadratic form. For \(U = \{u\}^T[K]\{u\}\) with \(\{u\}=\{u_1,u_2\}^T\) and symmetric \([K]=\begin{bmatrix}k_{11}&k_{12}\\k_{12}&k_{22}\end{bmatrix}\): \[U = k_{11}u_1^2 + 2k_{12}u_1u_2 + k_{22}u_2^2\] \[\frac{\partial U}{\partial u_1} = 2(k_{11}u_1+k_{12}u_2), \qquad \frac{\partial U}{\partial u_2} = 2(k_{12}u_1+k_{22}u_2)\] \[\left\{\frac{\partial U}{\partial u}\right\} = 2[K]\{u\}\] The same rule generalizes to any number of degrees of freedom.

Applying this to \(\Pi\) and setting \(\partial\Pi/\partial\{u^e\} = \{0\}\):

\[[K]\{u^e\} - \int_V [N]^T\{q\}\, dV - \int_S [N]^T\{p\}\, dS = \{0\}\]

In practice the integral \(\int [B]^T[D][B]\, dV\) is evaluated by numerical quadrature (Gauss integration). That topic appears in the Practical Considerations lecture.

11. Final Finite Element Equations

Collecting terms, the element nodal load vector is

\[\{f^e\} = \int_V [N]^T\{q\}\, dV + \int_S [N]^T\{p\}\, dS\]

and the governing finite element equation for the element is

\[[K]\{u^e\} = \{f^e\} \qquad \Longrightarrow \qquad \{u^e\} = [K]^{-1}\{f^e\}\]

A note on solving this in practice: \([K]^{-1}\) above is conceptual notation for "solve the linear system," not a recommended computational procedure. After assembling the element matrices into a global \([K]\) and applying the essential (displacement) boundary conditions, real FE codes solve the resulting linear system with a numerical solver (e.g. sparse Gaussian elimination or an iterative method) — they do not form \([K]^{-1}\) explicitly, which is far more expensive and numerically worse-conditioned than solving directly.

Summary — all quantities needed to solve a 3D elasticity problem by the finite element method:

Quantity Formula
Displacement approximation \(\{u\} = [N]\{u^e\}\)
Strain approximation \(\{\varepsilon\} = [B]\{u^e\}\)
Stress approximation \(\{\sigma\} = [D][B]\{u^e\}\)
Element stiffness matrix \([K] = \displaystyle\int_{V^e} [B]^T[D][B]\, dV\)
Element nodal load vector \(\{f^e\} = \displaystyle\int_{V^e} [N]^T\{q\}\, dV + \int_{S^e} [N]^T\{p\}\, dS\)

This is the exact 3D analogue of \([K]\{u\}=\{F\}\) from the 1D bar element you started the course with — same governing equation, richer \([N]\), \([B]\), and \([D]\).

The equation just derived, \([K]\{u^e\}=\{f^e\}\), is only the element level — every element in a mesh produces one. Getting to an answer means assembling those element matrices into a global system, then applying boundary conditions before solving:

Level Equation Typical size (8-node brick)
Element\([K^e]\{u^e\}=\{f^e\}\)\(24\times24\)
Global (assembled)\([K]\{u\}=\{F\}\)number of free global DOFs
After BCs applied\([K_{ff}]\{u_f\}=\{F_f\}-[K_{fc}]\{u_c\}\)free DOFs only

Assembly sums each element's contribution into the shared global DOFs at its nodes; applying essential (displacement) boundary conditions partitions the system into free (\(f\)) and constrained (\(c\)) degrees of freedom before the numerical solve described above. This assembly-and-solve process is covered in detail in later lectures — the point here is just to place the element derivation you just built inside the larger pipeline it feeds.

Summary of Key Equations

\[\{\varepsilon\} = [B(\vec x)]\{u^e\} \qquad \{\sigma\} = [D][B(\vec x)]\{u^e\}\]

\[[K] = \int_{V^e} [B]^T[D][B]\, dV \qquad \{f^e\} = \int_{V^e}[N]^T\{q\}\, dV + \int_{S^e}[N]^T\{p\}\, dS\]

\[[K]\{u^e\} = \{f^e\}\]

Check your understanding: put the pipeline in order

Starting from the nodal displacements \(\{u^e\}\) and ending at the element stiffness matrix \([K^e]\), put these in the order the finite element method actually computes them: \([D]\), \(\{\varepsilon\}\), \([B]\), \(\{\sigma\}\), \([N]\), \(\{u\}\), \([B^TDB]\).

Answer:

\[\{u^e\} \rightarrow [N] \rightarrow \{u\} \rightarrow [B] \rightarrow \{\varepsilon\} \rightarrow [D] \rightarrow \{\sigma\} \rightarrow \int[B]^T[D][B]\, dV \rightarrow [K^e]\]

Notice \([D]\) slots in independently of the \([N]\)→\([B]\) chain — it comes from the material (Constitutive Relations), not from the element geometry or shape functions, which is exactly why the same isotropic \([D]\) can be dropped into elements of any shape without re-derivation.

Check your understanding: pipeline with the load vector (harder)

Now include the load side. Arrange these in a valid computing order and say which steps are independent of each other: \([D]\), \([B]\), \([N]\), \(\int[N]^T\{q\}\,dV\), \(\int[N]^T\{p\}\,dS\), \(\int[B]^T[D][B]\,dV\), \(\{f^e\}\), and \([K]\{u^e\}=\{f^e\}\).

Answer: \([N]\) comes first, since both branches need it. The stiffness branch and the load branch are then independent and can be done in either order:

\[\begin{aligned} &\text{stiffness:}\quad [N] \rightarrow [B] \rightarrow \int[B]^T[D][B]\,dV = [K] \\ &\text{load:}\quad [N] \rightarrow \int[N]^T\{q\}\,dV + \int[N]^T\{p\}\,dS = \{f^e\} \end{aligned}\]

The two branches meet only in the last step, \([K]\{u^e\}=\{f^e\}\), which is an equation to be solved for \(\{u^e\}\) (after assembly and boundary conditions), not a quantity computed forward. \([D]\) enters only the stiffness integral; the load vector never touches \([D]\) or \([B]\).
